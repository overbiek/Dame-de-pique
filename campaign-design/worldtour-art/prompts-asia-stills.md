# Asia: the 30 location stills (one image per prompt)

**Make 30 separate images, one for each prompt below: 10 cities x 3 places.** One image per prompt, one prompt at a time. Do not ask Gemini for a collage, a grid, a contact sheet or several places in one picture. Every prompt below produces exactly **one single full-frame picture of one place**.

Each city has three stills, the same set-up as Europe (`stills-prologue-and-europe.md` section C):

| Suffix | Where | Used for |
|---|---|---|
| `_1` | Location A, the first public tournament place | tables 1-4 of the city |
| `_2` | Location B, the second public tournament place | tables 5-9 |
| `_k` | the Keeper's Table venue, always empty of people | table 10 |

They sit behind the stories and behind the card table during a hand. They are NOT the level-select postcards (see `prompts-asia-level-select.md`).

## How to make each image

1. Open the Gemini app. **No reference image is needed** for these. Start a **new chat for each image** so the places do not mix.
2. Paste **one** complete prompt below. Each prompt already contains everything (the place, the light, the people rule, the calm lower third and the no-text rule), so you only paste one block.
3. Generate **one** image, 16:9 wide, 1920x1080 or larger. If it is not right, regenerate that same prompt; do not move on until it is good.
4. Save it at full size (do not crop) as `afbeeldingen/World Tour/Cities/<id>.jpg` using the id in the heading, and tell Claude. Claude converts them and adds them to the app (they go behind that city's stories and card tables).

What every picture must have (already written into each prompt): realistic and photographic (not illustration, not painterly, not CGI), dark, warm and a little moody to sit with the game's emerald and brass, a calm lower third because dialogue cards sit there, no readable text anywhere (shop signs, neon and billboards show only as glowing colour), no recognisable faces. **Public places** (`_1`, `_2`) show a few official round card tables with dark green baize and small anonymous figures far away. **Keeper's Table rooms** (`_k`) are always completely empty of people.
